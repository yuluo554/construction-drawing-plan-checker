# data/ 数据台账（Dataset Registry）

本目录存放赛题所需的样本数据与知识库数据。**每份数据必须登记来源与用途**，涉企数据须脱敏。

## 目录结构与现状

```
data/
├── 施工图纸/          施工图样本
│   ├── FloorPlanCAD/  开源 FloorPlanCAD 数据集抽样（真实 CAD 图纸渲染图，用于图纸版面/符号解析测试）
│   └── 自制样例/      gen_sample_drawing.py 程序化生成的平法标注图纸（DXF+PDF+真值JSON+参数卡），解析器回归测试用
├── CAD样例/
│   ├── libredwg/      LibreDWG 官方测试图（R14~2018 多版本 DWG/DXF，测试 DWG 转换与 DXF 解析）
│   └── ezdxf/         ezdxf 官方 DXF 样例（图层/块/标注，测试实体级解析）
├── 法规标准/          法规、规范、指南（知识库原始文件）
│   ├── 建办质〔2021〕48号-危险性较大的分部分项工程专项施工方案编制指南.docx
│   └── 危大工程范围清单.json   （自建机器可读阈值表，校核规则库种子数据）
└── 施工方案/          施工方案范本与样例（docx/pdf）
```

## 数据合规约定

1. 全部公开数据在表中登记来源与许可；无法确认许可的不得入库；
2. 命题单位/企业案例脱敏（工程名、人名、地名、坐标），仅用于比赛；
3. 规范文本仅做条款级检索引用（显示条款号与必要原文），不做全文再分发。
