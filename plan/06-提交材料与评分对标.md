## 2. 提交清单（Checklist）

- [ ] **系统/原型**（网页版）：Docker Compose 一键部署包 + 演示账号 + 预置示例项目
- [ ] **核心代码框架**：`code/` 仓库（解析层/参数卡/规则引擎/Agent 编排模块划分清晰，README 含架构图与运行说明）
- [ ] **技术报告**：按 §3 大纲撰写（20–30 页）
- [ ] **演示视频**：≤5 分钟 1080P（脚本见 §4）
- [ ] 附加：数据集说明与标注样例、评测结果表、（可选）论文式创新点说明

## 3. 技术报告大纲

1. 项目背景与需求分析（引用赛题四大痛点 → 能力映射表）
2. 技术路线与系统架构（六层架构图、数据流图、Agent 工作流）
3. 模型与算法设计
   - 3.1 图纸解析：版面分析、平法标注解析器（规则+LLM 混合、合法性校验）
   - 3.2 方案理解：章节树、Schema 约束抽取、防幻觉机制
   - 3.3 知识库：条文结构化、向量检索、规则 DSL 设计
   - 3.4 协同校核：参数对齐算法、一致性/指标/合规三类判定
4. 数据集构建（来源、自制管线、标注规范、规模统计）
5. 测试效果（抽取 F1、校核查全/查准、端到端时长；消融：规则-only vs 规则+LLM）
6. 应用分析（三类场景走查、用户操作步骤、效率提升测算：单项目方案校核 2 人日 → 10 分钟）
7. 总结与展望（图纸智能生成、多维协同、与BIM/审查系统对接）

## 4. 演示视频脚本（5 分钟分镜）

| 时间 | 画面 | 讲解要点 |
|------|------|----------|
| 0:00–0:30 | 痛点引入（人工翻图对照照片 vs 系统界面） | 四大痛点 → 一句话方案："图纸×方案，一键协同校核" |
| 0:30–1:30 | 上传图纸（结施总说明+梁配筋图）+ 模板专项方案 | 解析过程可视化：图框识别→参数卡逐步生成 |
| 1:30–2:30 | 校核结果页 | 三类问题各举一例：①方案 C30 vs 图纸 C35（致命）②高支模 8.5m 属超规模需专家论证未声明 ③方案缺"应急处置措施"章节 |
| 2:30–3:30 | 双文档证据联动 | 点击问题 → 图纸 bbox 高亮跳转 + 方案原文高亮；依据条款卡片（RAG） |
| 3:30–4:15 | 报告导出 + 危大合规义务清单 | 一键生成校核报告；危大识别演示 |
| 4:15–5:00 | 方案草稿辅助编制 + 参数联动修订（前沿） | 图纸参数→方案概况自动填充；总结与致谢命题单位场景支持 |

> 演示用预置数据：1 个演示项目 = 5–8 张结构图纸（矢量 PDF）+ 1 份模板专项方案（植入 6–8 处典型错误）。

## 5. 现场答辩预案（如需）
