## 一页纸方案摘要

**一句话**：把施工图与施工方案各自解析成统一的"工程参数卡"，用规则引擎+RAG 规范库做参数对齐、指标核查与危大合规判断，输出**每条带证据定位**的校核报告——"图纸×方案，一键协同校核"。

**六层架构**：接入 → 解析（PDF/OCR/CAD/平法） → 表示（参数卡） → 智能（Agent+RAG+多模态） → 校核（一致性/指标/合规） → 应用（高亮/报告/问答）。

**五大创新点**：①工程参数卡中间表示 ②平法标注专用解析器 ③规则+RAG 双通道合规判断 ④危大工程自动识别（31号文阈值表机器可读） ⑤参数联动修订（前沿探索）。
