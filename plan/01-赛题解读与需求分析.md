# 01 赛题解读与需求分析

> 赛题10：面向工程建造的AI智能体——施工图与施工方案协同智能系统
> 命题单位：南通市达欣工程股份有限公司（房屋建筑施工总承包企业）

---

## 1. 赛题原文要点

**背景痛点**（赛题介绍）：施工图与施工方案是设计落地、现场实施、安全管控的核心依据，当前存在四大问题：
1. 二者**数据不互通**（图纸在 CAD/PDF 世界，方案在 Word 世界）；
2. **校核依赖人工**（技术员逐页翻图、逐条对照，效率低易漏项）；
3. **关键参数易出错**（混凝土强度、构件截面、脚手架/模板支撑参数等在两套文档间不一致）；
4. **方案编制与图纸匹配度不足**（方案模板化、空话多，与本项目图纸脱节）。

**任务要求**：研发一款 AI 智能体，实现施工图与施工方案的**协同处理与智能校核**：
- 对**施工图纸**进行智能解析与信息提取；
- 对**施工方案**进行结构化理解与关键参数校核；
- 实现**图纸信息与方案参数的一致性校验**、**关键指标智能核查**、**方案合规性辅助判断**；
- 鼓励探索**图纸智能生成、优化修改**等前沿方向；
- 形成可辅助工程技术人员开展**方案编制、图纸应用、合规校核**的一体化智能工具。

**提交材料**（网页版 / PC 客户端 / 算法原型包三选一）：

| # | 材料 | 要求 |
|---|------|------|
| 1 | 系统/原型 | 具备图纸处理、方案分析、关键参数校核、结果展示等功能 |
| 2 | 核心代码框架 | 智能体核心逻辑、数据交互与协同处理模块源代码 |
| 3 | 技术报告 | 技术路线、模型与算法设计、数据集构建、测试效果与应用分析 |
| 4 | 演示视频 | 5 分钟内展示实际工程场景下的应用效果 |

**评分标准**：创新性、工程实用性、技术完整性、场景贴合度、演示效果，综合评定。

**技术支持**：命题单位提供典型工程应用场景、实际案例与技术方向指导 → **尽早联系命题单位获取真实图纸+方案案例，是场景贴合度得分的关键**。

## 2. 痛点 → 系统能力转译

| 赛题痛点 | 转译为系统能力 | 对应功能模块 |
|----------|----------------|--------------|
| 数据不互通 | 图纸/方案统一解析为**机器可读的"工程参数卡"** | M1 图纸解析、M2 方案解析 |
| 校核依赖人工 | **自动对齐 + 差异比对**，生成带证据的问题清单 | M4 校核引擎 |
| 关键参数易出错 | 参数级**一致性校验 + 指标复算** | M4 校核引擎 |
| 方案与图纸匹配不足 | 方案**章节完整性/参数引用**对照图纸核查，辅助编制 | M4 校核引擎、M2 方案解析 |
| （合规管控隐含需求） | **危大工程识别 + 合规性辅助判断**（37号令/31号文/2021编制指南） | M3 知识库、M4 校核引擎 |

## 3. 功能需求清单（FR）

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| FR1 | 图纸上传与解析 | 支持 PDF（矢量/扫描）、DWG/DXF、图片；提取图框标题栏、构件、配筋、材料、表格 | P0 |
| FR2 | 方案上传与解析 | 支持 docx/pdf；章节树 + 结构化参数抽取（工程概况、分项工程、关键参数） | P0 |
| FR3 | 一致性校验 | 图纸参数卡 ↔ 方案参数卡自动对齐比对，输出差异清单（冲突/缺失/一致） | P0 |
| FR4 | 关键指标核查 | 混凝土强度匹配、构件截面引用、脚手架/模板支撑参数与规范阈值核对、参数复算 | P0 |
| FR5 | 合规性辅助判断 | 危大工程自动识别（规模阈值）→ 是否需专项方案/专家论证 → 方案章节完整性对照 | P0 |
| FR6 | 结果展示与报告 | 问题分级列表、双文档证据高亮定位（图纸 bbox / 方案章节）、校核报告导出 | P0 |
| FR7 | 知识问答（RAG） | 针对规范条文、危大政策的智能问答，回答附条文出处 | P1 |
| FR8 | 方案辅助编制 | 基于图纸参数卡自动填充方案"工程概况/主要参数"章节草稿 | P1 |
| FR9 | 图纸智能生成/修改（前沿加分） | 参数变更 → 联动更新方案文本建议 / 简单构件图元生成探索 | P2（展示性 demo） |

## 4. 用户与典型场景

**目标用户**：施工单位项目技术员（方案编制）、项目总工（方案审核）、安全员（危大管控）。

**三个演示场景**（对应评分的"场景贴合度"）：
1. **方案编制前**：上传图纸 → 自动生成"工程概况 + 结构参数"草稿，填充方案模板（FR8）；
2. **方案审核中**：图纸+方案一键校核 → 输出参数不一致、危大遗漏、指标超限三类问题及修改建议（FR3-5）；
3. **危大合规检查**：识别方案中的深基坑/高支模/脚手架是否达到危大或超规模阈值，提示专项方案与专家论证义务（FR5）。

## 5. 边界与非目标（防 scope 失控）

- 不做全专业（给排水/暖通/电气）全覆盖，聚焦**土建结构 + 安全措施类方案**（模板、脚手架、混凝土、基坑）；
- 不做 BIM 三维重建；图纸理解以二维图 + 标注/表格为主；
- 不替代审查机构职能，定位为**辅助校核工具**，输出"问题线索 + 依据"由人最终确认；
- 不承诺对任意规范全文做精确解释，规范问答以**条文检索+原文引用**为准，避免幻觉。

## 6. 关键成功因素

1. **尽早拿到命题单位的真实图纸与方案案例**（评分权重最高的场景贴合度）；
2. 校核结论**每条带证据**（图纸图号+bbox、方案章节号），可溯源、可解释——评审最看重的工程实用性；
3. 端到端 demo 流畅：上传→解析→校核→报告 全链路 3 分钟内可演示；
4. 平法标注解析、危大识别两项"专业硬功夫"形成技术亮点与壁垒。
