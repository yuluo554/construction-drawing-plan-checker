# 07 竞品与生态参考（速览）

> 用途：明确差异化定位，避免重复造轮子，吸收可用组件。调研日期 2026-09-26。

## 1. SmartReview（GitHub: CallStorm/SmartReview）——施工方案审核系统

**能力**（据其 README）：账号角色、方案类型与编制依据维护、**按方案类型绑定 Word 模板（标题树 JSON）**、方案审核任务与报表、知识库、审核策略、大模型接入、OnlyOffice 集成。

**对我们的启示与差异化**：
- 其"方案类型→Word 模板→标题树"的做法与本计划 M2 的"指南章节先验+章节树对照"一致，验证了路线可行性；
- 其审核对象是**方案文本自身**（章节完整性、知识库比对），**未涉及施工图解析**——本计划的"图纸参数卡×方案参数卡一致性校核 + 平法解析"是明确差异化，也正好命中赛题"图纸与方案协同"的核心；
- 样例文档 `sample-high-support-formwork.docx` 已收入 `data/施工方案/`，可作方案解析测试输入。

## 2. 开源数据/工具生态（已在 plan/04 展开使用）

| 资源 | 用途 |
|------|------|
| FloorPlanCAD（HF: Voxel51/FloorPlanCAD） | 15k+ 真实 CAD 平面图渲染 + 符号标注，图纸解析预研与测试 |

| bge-m3 + FAISS | 条文级 RAG 检索 |

## 3. 定位一句话（对外表述）

> SmartReview 等现有工具解决了"方案怎么管、怎么审文本"；本系统解决赛题真正的痛点——**图纸与方案两张皮**：图纸解析为参数卡，与方案参数卡自动对齐校核，危大合规自动判定，每条结论可回溯到图纸坐标与方案原文。
