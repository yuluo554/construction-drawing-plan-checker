# 04 数据集构建计划

## 1. 数据需求清单

| 类别 | 用途 | 规模目标 | 来源 |
|------|------|----------|------|
| 施工图样本（矢量PDF/DXF） | 图纸解析开发与测试 | 30–50 张（梁/柱/板配筋图、总说明、平面图） | ①命题单位案例 ②开源数据集 ③程序化自制 |
| 施工图样本（扫描/图片） | OCR 通路测试 | 10–20 张 | 命题单位/公开扫描件 |
| 施工方案样本（docx/pdf） | 方案解析与合规判断 | 20–40 份（模板、脚手架、基坑、混凝土浇筑等） | ①政府范本 ②命题单位脱敏案例 ③模板站样例 |
| 法规/规范库 | RAG 与规则依据 | 核心文件 8–12 部 | 官方发布（gov.cn 等） |
| 标注数据 | 抽取评测 | 图纸参数卡 50 份、方案参数卡 30 份 | 团队人工标注 |
| 端到端校核评测集 | 系统指标报告 | 20 组"图纸+方案+标准答案差异清单" | 自制（植入已知错误） |

## 3. 后续获取渠道（优先级）

1. **命题单位实际案例**（最高优先）：发函/联系获取 2–3 个真实项目的图纸集与施工方案（脱敏）——直接决定"场景贴合度"；同时向命题单位确认典型校核场景清单；
2. **政府公开范本**：各省住建厅发布的专项施工方案编制指南/范本、招标网站公开的已批复专项方案附件；
3. **开源数据集**：
   - FloorPlanCAD（15k+ CAD 平面图，HF `Voxel51/FloorPlanCAD`，本次已抽样）；
   - ArchCAD-400K（5.5k 建筑图纸向量化数据集）；
   - ezdxf / LibreDWG 官方样例（已入 data/）；
4. **程序化自制**（重要保底）：用 ezdxf 按 22G101 平法语法**程序化生成**带梁/柱集中标注、原位标注的配筋图 DXF+PDF（参数随机化），可低成本造 500+ 张带真值标注的图纸，用于解析器训练/评测——**解决"没有真值标注"的核心难题**；
5. **规范库**：GB 50010、GB 55008、JGJ 130、JGJ 162、JGJ 311、37号令、31号文、2021-48指南、公司施工组织设计模板等（PDF 原文以官方/正版渠道录入，注意版权，仅内部使用）。

## 4. 标注规范（参数卡标注）

- 图纸：每张图标注 `{图号, 图名, 图纸类型, 构件列表[{entity_id, 类型, 截面, 配筋, 材料, 位置, bbox}]}`
- 方案：按 M2 Schema 标注 `{工程概况, 分部分项, 关键参数[], 危大相关}`，每个值附原文片段；
- 工具：Label Studio（bbox 标注）+ 表格化 JSON 校对；双人标注 + 交叉仲裁，抽样一致率 ≥ 95%。

## 5. 评测集与指标

| 环节 | 指标 | 目标 |
|------|------|------|
| 图纸字段抽取 | 字段级 P/R/F1 | 矢量 F1≥90%，扫描 F1≥75% |
| 方案字段抽取 | 字段级 F1 | ≥88% |
| 一致性校验 | 差异项查全/查准 | 查全 ≥90%（演示集），误报率 ≤10% |
| 危大识别 | 判定准确率 | ≥95%（阈值表规则驱动，可达成） |
| 端到端 | 20 组评测集平均处理时长 | ≤3 分钟/组 |

## 6. 数据合规
- 所有公开数据记录来源与许可（data/README.md 台账）；
- 命题单位/企业案例一律脱敏（工程名、人员、坐标模糊化），仅用于比赛演示；
- 规范原文仅作检索引用（显示条款号+必要原文），不做全文再分发。
