# 03 关键模块详细设计

## M1 图纸智能解析（施工图 → 图纸参数卡）

### 1.1 输入分类与预处理

| 输入 | 判别 | 处理路径 |
|------|------|----------|
| 矢量 PDF | 文本层可提取（字符数>阈值） | PyMuPDF 提取文本+坐标；pdfplumber 提取表格 |
| 扫描 PDF/图片 | 无文本层 | 转图像（300dpi）→ PaddleOCR + PP-StructureV3 版面/表格还原 |
| DWG | 二进制 | ODA File Converter → DXF → ezdxf 解析 |
| DXF | 文本 | ezdxf 直接解析 |

### 1.2 解析流水线

```
①图框/标题栏定位（右下角区域：工程名称/图号/图名/比例/版本/出图日期）
②图纸类型分类（平面图/立面/剖面/结施大样/说明/目录）——规则(图框标题关键字)+VLM 兜底
③文本块空间聚类 → 按图面分区（轴网区/标注区/表格区/说明区）
④表格提取：图纸目录、柱表(框架柱编号/截面/纵筋/箍筋/标高)、门窗表、材料表、层高表
⑤平法标注解析（见1.3）
⑥说明文字抽取：混凝土强度等级、钢筋级别、焊条型号、保护层厚度（"总说明"页）
⑦输出：图纸参数卡 + 每字段的 bbox 证据
```

### 1.3 平法标注解析器（核心亮点）

**规则层**（22G101 图集语法，正则+槽位填充）：
- 梁：`KL1(3) 300×600` → 框架梁1、3跨、截面300×600；`Φ8@100/200(2)` → 箍筋直径8、加密区间距100/非加密区200、双肢箍；`2Φ22; 3Φ18` → 上部通长筋/下部纵筋；`G4Φ12` → 构造腰筋；原位标注按轴线位置对齐到跨。
- 柱：`KZ1 600×600 24Φ22 4Φ12@100/200` → 角筋/纵筋/箍筋，结合柱表逐楼层段解析。
- 板：`LB1 h=120 B: XΦ12@150 YΦ10@180 T: XΦ12@150` → 板厚/底部/顶部双向配筋。
- 符号归一：`Φ/HPB300、C/HRB400、T/LB/B/` 等字典表；`@`、加密区、支座负筋截断规则。

**LLM 兜底层**：无法匹配的异体写法 → 把标注原文+上下文送 LLM 抽槽位，结果经"符号合法性校验"（直径数值范围、间距范围、钢筋等级符号表）后才入库，非法值丢弃并标记待人工。

**精度目标**：矢量 PDF 上梁/柱标注 F1 ≥ 90%（演示集实测），扫描件 ≥ 75%。

### 1.4 证据定位
所有字段记录 `page + bbox`，前端 PDF.js 上渲染半透明高亮框，点击问题项自动跳转——**评审现场最有说服力的功能**。

## M2 施工方案结构化理解（方案 → 方案参数卡）

### 2.1 文档结构解析
- docx：python-docx 读段落/样式/表格 → 标题树（Heading 级别）+ 表格序列；
- pdf：PyMuPDF 文本 + 字号/加粗聚类重建章节树；计算书表格 PP-Structure 还原。

### 2.2 LLM 结构化抽取（带 Schema 约束，JSON mode）

抽取 Schema（方案参数卡）：
```json

  "工程概况": {"建筑面积": "", "层数": "", "建筑高度": "", "结构类型": "", "基础形式": ""},
  "分部分项": ["基础工程", "主体结构", "脚手架工程", "模板工程", "起重吊装"],
  "关键参数": [
    {"类别": "混凝土", "部位": "基础底板", "强度等级": "C35", "证据": {"章节": "3.2", "原文": "..."}},
    {"类别": "脚手架", "型式": "落地扣件式", "立杆纵距": 1.5, "立杆横距": 1.05, "步距": 1.8, "搭设高度": 24.5, "...": ""}
```

- **模板先验**：以《危大工程专项施工方案编制指南》（建办质〔2021〕48号，已存 `data/法规标准/`）的标准章节为对照模板，检测方案缺失章节；
- 抽取采用**分段滑动窗口 + 逐字段引用原文**，防幻觉：每个值必须携带原文片段，与原文 diff 校验。

## M3 规范知识库与规则库

### 3.1 三层结构
1. **文件层**：法规/规范原文（PDF/docx/md）→ `data/法规标准/`；
2. **条文层**：条款级切分 + 结构化（`{规范号, 条款号, 适用对象, 阈值, 原文}`）→ 向量库（bge-m3 + FAISS）供 RAG；
3. **规则层**：机器可读校核规则 JSON（可执行），示例：

```json
{
  "rule_id": "R-SJ-001",
  "名称": "混凝土强度等级图纸-方案一致性",
  "类型": "一致性",
  "对齐键": "混凝土.强度等级@部位",
  "左源": "图纸参数卡", "右源": "方案参数卡",
  "判定": "不等 → 严重冲突；一方缺失 → 提示补录",
  "级别": "致命",
  "依据": "GB 50010-2010(2015版) 第4.1.2条；设计文件",
  "建议": "以图纸总说明为准修改方案混凝土强度等级"
}
```

### 3.2 危大工程识别清单（优先建设）
依据住建部令37号、建办质〔2018〕31号附件1/2、建办质〔2021〕48号，整理为机器可读阈值表（自建核对版存 `data/法规标准/危大工程范围清单.json`，以官方文本为准）：

| 类别 | 危大（需专项方案） | 超规模（需专家论证） |
|------|-------------------|---------------------|
| 基坑工程 | 开挖深度 ≥ 3m；或 <3m 但地质条件/环境复杂 | 开挖深度 ≥ 5m |
| 模板工程及支撑体系 | 搭设高度 ≥5m；跨度 ≥10m；施工总荷载 ≥10kN/m²；集中线荷载 ≥15kN/m | 高度 ≥8m；跨度 ≥18m；总荷载 ≥15kN/m²；线荷载 ≥20kN/m |
| 起重吊装 | 单件重量 ≥100kN；起重机械安装拆卸 | 单件 ≥100kN 的吊装且起重量300kN及以上等情形 |
| 脚手架工程 | 落地式钢管脚手架 ≥24m；附着式升降；悬挑式 | 落地式 ≥50m；提升高度 ≥150m 的附着式 |
| 拆除/暗挖 | 拆除工程；暗挖工程 | 特殊建构筑物拆除；16m 以上人工挖孔桩等 |

### 3.3 规则库建设节奏
- 一期（演示必备）：30–50 条核心规则（混凝土/钢筋/截面一致性 10 条 + 模板/脚手架阈值 10 条 + 危大识别 10 条 + 章节完整性 10 条）；
- 二期：扩展至 100+ 条，覆盖基坑、起重吊装、临电、消防。

## M4 协同校核引擎（三类校核）

### 4.1 一致性校验（图纸卡 × 方案卡）
1. **实体对齐**：别名归一字典（"砼/混凝土"、"圆钢/HPB300"）+ 属性名归一（"立杆横距/横距/纵距方向校准"）；
2. **比对**：逐属性 → 相等/不等/单方缺失 → 生成差异项（含左右证据、置信度）；
3. **消歧**：多值冲突（图纸多楼层不同强度）→ 按"部位对齐"细化，无法定位则标记"待人工确认"。

### 4.2 关键指标核查
- **阈值类**：脚手架步距/立杆间距 vs JGJ130 上限、悬挑型钢锚固长度、模板支撑步距 vs 高支模规定；
- **复算类**（calc 工具）：纵筋配筋率复核、立杆稳定性验算参数带入（演示复算过程而非替代计算书）、吊装重量与机械起重能力匹配；
- 输出：`通过/超限/无法判定` 三态，超限项附规范条款与计算过程摘要。

### 4.3 合规性辅助判断（流程链）
```
识别危大分项 → 判定规模档位(危大/超规模/非危大)
  → 检查方案是否含对应专项章节（对照2021-48指南目录）
  → 检查是否声明专家论证/审批签署栏
  → 输出合规义务清单与缺失项
```

### 4.4 问题分级与报告
- 级别：🔴致命（参数冲突/超规模未论证）、🟡一般（超限/缺失）、🔵建议（完善项）；
- 报告：问题清单表（问题描述/级别/图纸证据/方案证据/依据条款/修改建议）+ 总体结论 + 签署建议，docx/pdf 一键导出。
